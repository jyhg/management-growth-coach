# Knowledge Inbox

This file is append-only. Use it for user-approved public management knowledge before curating anything into the stable management library.

Do not write directly to `management_library.md` after one accepted answer. First save candidate knowledge here, then periodically curate repeated or high-value items.

## Append-only Entry Template

```markdown
## YYYY-MM-DD - short title

- Date:
- Scene:
- User question summary:
- Sanitized web query:
- Source title and URL:
- Key insight:
- Applicability boundary:
- Relation to local knowledge:
- User acceptance:
- Suggested library action:
```

## Public Safety

Before saving, remove:

- company names
- product names
- personal names
- internal project names
- team-specific details
- private metrics
- local file paths
- credentials or tokens

Persist only the generalized management question and public source-backed insight. do not persist sensitive details.
