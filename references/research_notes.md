# Research Notes

Use this file for source-backed management learning that becomes useful more than once.

## Research Boundary

When browsing:

- prefer primary, academic, official, or established management sources
- record source title and URL
- summarize only the part useful for the user's current situation
- convert theory into observable management action
- cite sources in the final response

## Web Research Assisted Learning

Use local knowledge first, then web research only when useful. This workflow is:

1. 本地优先: inspect `training_notes.md`, `management_library.md`, and `management_playbook.md`.
2. 联网补充: browse credible public sources when the user asks for current, sourced, or insufficiently covered knowledge.
3. 问题脱敏 / sanitize: rewrite the query into a generic management question before browsing.
4. 融合回答: integrate local and external knowledge into one answer.
5. 用户确认: ask whether the user accepts the answer and whether to save external knowledge.
6. 候选沉淀: if accepted and saving is requested, append to `knowledge_inbox.md`.

Do not write directly to `management_library.md` after one accepted answer. Stable library updates require later curation.

## Query Sanitization

Before web search, remove:

- company names
- product names
- personal names
- internal project names
- team-specific details
- private metrics
- local file paths
- credentials or tokens

Use generic management questions, for example:

- cross-functional project collaboration stakeholder alignment management framework
- constructive feedback model manager employee missed deadline
- psychological safety team conflict leadership
- management framework for cross-team business value alignment

## Source Quality

Prefer credible public sources:

- official institutions
- universities
- recognized management publications
- original framework authors
- reputable books
- professional bodies

Avoid unattributed summaries, SEO listicles, content farms, and anecdotal claims unless clearly labeled.

## Web-Research Answer Structure

When web research is used, include:

- 场景判断
- 本地知识命中
- 外部可信资料补充
- 融合判断
- 下一步动作
- 可沉淀知识
- 确认问题

The confirmation question should ask:

- 是否认可本次回答？
- 如果认可，是否要把外部公开知识保存到 `references/knowledge_inbox.md`？

## Useful Research Lenses

- DISC: use as a communication hypothesis, not a fixed identity.
- SMART/MBO: use for goal clarity and autonomy.
- Q12: use for engagement and team climate checks.
- Psychological safety: use when members avoid speaking, admitting errors, or challenging plans.
- Feedback models: use fact-impact-action language and avoid vague judgment.
- Situational leadership: adapt support and direction to readiness.
- 5 Whys: use for root cause, but stop when action becomes clear.
