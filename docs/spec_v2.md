# management-growth-coach Spec v2

## Change From v1

v1 validated skill structure and required references. v2 adds scenario-quality requirements.

## Scenario Quality Requirements

For each DISC profile, the skill must provide:

- a communication adaptation
- a likely blind spot
- a concrete management action
- a risk of misuse

## Longitudinal Quality Requirements

For recurring use over six months, the skill must define:

- weekly session opening check
- monthly pattern review
- quarterly personal context refresh
- commitment follow-up mechanism
- playbook update criteria
- anti-repetition mechanism

## Failure Modes To Address

- D profile: manager escalates too quickly and misses stakeholder preparation.
- I profile: manager gives feedback factually but ignores public recognition damage and relationship repair.
- S profile: manager frames change as a mandate and creates silent resistance.
- C profile: manager treats quality concern as obstruction and loses standards.
- Six-month usage: logs accumulate but no pattern summary or behavior change is checked.
