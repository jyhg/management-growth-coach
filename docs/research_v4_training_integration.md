# Research v4 - Training Framework Integration

## Goal

Integrate management theories and tools from the local training summary into the public skill initialization knowledge.

## Sanitization Rule

Only keep generalized management frameworks, checklists, and tools.

Do not include:

- local file names
- company names
- product names
- personal names
- private 1:1 content
- business-specific project examples
- screenshots or source document paths
